# ComputerAsset

### 企业电脑资产管理系统 / Enterprise Computer Asset Management System

[中文文档](README.zh.md) | [English](README.en.md)

覆盖电脑资产从入库到报废的完整生命周期，提供可视化仪表盘、细粒度权限控制与完整的审计追踪。

An enterprise computer asset management system covering the full lifecycle from stock-in to retirement, with visual dashboards, fine-grained access control, and complete audit trails.
